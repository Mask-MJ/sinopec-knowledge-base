## 第 5 周（3/1 ~ 3/7）：监控日志模块开发（上）

### 本周工作内容

1. **登录日志功能开发**
   - 登录日志表（LoginLog）数据模型定义：username, status, ip, address, browser, os, message, loginTime
   - Prisma schema 编写与数据库迁移
   - 登录成功/失败时自动记录日志（拦截器实现）
   - IP 地址解析与地理位置获取
   - 浏览器与操作系统信息提取（User-Agent 解析）
   - 登录日志查询接口（GET /login-log），支持分页与筛选
   - 登录日志详情接口（GET /login-log/:id）

2. **操作日志功能开发**
   - 操作日志表（OperationLog）数据模型定义：title, businessType, module, username, ip, address
   - AOP 切面日志记录方案设计与实现（NestJS EventEmitter 事件监听模式）
   - 业务类型枚举定义（0其它 1新增 2修改 3删除）
   - 关键模块操作自动记录（用户/角色/菜单/部门/岗位/字典 6 个模块已接入）
   - 操作日志查询接口（GET /operation-log），支持分页与筛选
   - 操作日志详情接口（GET /operation-log/:id）

3. **系统管理前端页面开发**
   - 实现用户、角色、部门、岗位、菜单、字典 6 大管理页面的完整 CRUD 功能
   - 角色管理含菜单授权树选择器
   - 菜单管理支持多类型（目录/菜单/按钮/内嵌/外链）+ 高级设置
   - 字典管理支持两级结构（字典类型 + 字典数据项）

### 下周工作计划

- 完成服务器监控数据采集功能

## 第 7 周（3/15 ~ 3/21）：安全加固与架构优化

### 本周工作内容

1. **安全加固（6 项）**
   - 防用户枚举：登录接口统一返回"用户名或密码错误"，不区分具体原因
   - 文件名清理：上传和下载统一使用 sanitizeFilename 白名单正则过滤，防止路径穿越
   - 开放重定向防护：用 URL 对象严格校验跳转目标，替代正则匹配
   - 移除硬编码凭证：登录表单中的开发账号密码改为环境变量注入
   - 权限守卫加固：增加重定向校验和异常恢复逻辑
   - 类型安全强化：大幅减少 `any` 类型使用，替换为 `unknown` + 类型守卫

2. **架构优化**
   - 种子数据重构：从 JSON 文件迁移为 TypeScript 常量，通过 NestJS 生命周期模块自动执行
   - 事务安全：部门管理操作增加数据库事务保护
   - 服务端通用层重构：改进 Prisma 配置、auth 模块、common 层结构
   - API 规范对齐：全部 update 接口改为 path params 风格
   - Token 刷新机制重写：使用 resolve/reject 队列模式处理并发刷新

3. **Bug 修复（4 项）**
   - 修复 Token 刷新竞态条件：`return fetch()` 加 `await`，确保刷新完成再释放锁
   - 修复 RAGFlow API v0.20 → v0.24 不兼容：全量对齐接口路径和参数
   - 修复默认 Embedding 模型错误：改为 `BAAI/bge-large-zh-v1.5`
   - 修复 Lefthook 钩子丢失未暂存代码：配置 `skip_unstaged: true`
